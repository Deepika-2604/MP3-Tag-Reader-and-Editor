# MP3 Tag Reader and Editor Using C

## About the Project
A command-line application developed in C to read, display, and modify ID3v2.3 metadata in MP3 audio files.

## Features
- Display MP3 metadata such as title, artist, album, year, genre, and comments.
- Modify selected metadata fields using command-line arguments.
- Parse ID3v2.3 headers and metadata frames.
- Perform binary file handling operations.
- Preserve audio data during metadata editing.

## Technologies Used
- C Programming
- File Handling
- Pointers and Structures
- Command-Line Arguments
- Binary File Processing

## Concepts Learned
This project strengthened my understanding of C programming, file handling, string manipulation, and modular programming.
